# Cryptocurrency Token Parser

## Описание проекта

**Cryptocurrency Token Parser** — это Python-приложение для парсинга и анализа информации о криптовалютных токенах с публичной страницы [Etherscan.io](https://etherscan.io/tokens).

Программа извлекает данные о токенах (название, цена в USD, ссылка на страницу токена) и выводит их в отсортированном виде, позволяя пользователю управлять количеством выводимых записей.

## Основные возможности

 **Автоматический парсинг HTML** — извлечение информации о криптовалютах со страницы tokens  
 **Извлечение ключевых данных** — получение названия токена (или тикера), цены в USD и прямой ссылки на страницу токена  
 **Сортировка по цене** — автоматическая сортировка токенов от дорогих к дешёвым (по убыванию)  
 **Управление выводом** — пользователь может указать количество позиций для отображения  
 **Красивый вывод** — форматированная таблица с выравниванием колонок

## Как установить

### Требования
- Python 3.7+
- pip (менеджер пакетов Python)

### Шаг 1: Клонировать или скачать проект

```bash
git clone <ссылка-на-репозиторий>
cd parse_crypto
```

### Шаг 2: Установить зависимости

```bash
pip install -r requirements.txt
```

Или установить библиотеки вручную:

```bash
pip install requests beautifulsoup4
```

## Как запустить

### Базовый запуск (вывод 10 токенов по умолчанию)

```bash
python parse_crypto.py
```

Программа предложит ввести количество записей. Нажмите Enter для использования значения по умолчанию (10 токенов).

### Запуск с указанием количества токенов

```bash
python parse_crypto.py
```

Введите желаемое количество (например, `15`, `20`) и нажмите Enter.

## Описание функций

### `getHtml() -> str`
Получает HTML-содержимое страницы Etherscan.io/tokens с помощью HTTP-запроса. Включает обработку ошибок и корректные заголовки User-Agent.

**Возвращает:** HTML-страницу в виде строки или сообщение об ошибке.

### `parseHtml(html: str) -> list`
Парсит полученный HTML и извлекает информацию о каждом токене:
- **Название** — название или тикер токена
- **Цена (USD)** — стоимость в американских долларах (как число)
- **Ссылка** — ссылка на страницу токена на Etherscan

**Параметры:** 
- `html` — HTML-содержимое страницы

**Возвращает:** Список списков `[название, ссылка, цена]`

### `printArr(arr: list, count: int) -> None`
Выводит массив токенов в красивом формате таблицы. Автоматически сортирует по цене (от большей к меньшей).

**Параметры:**
- `arr` — список токенов
- `count` — количество записей для вывода

### `parseTokens(count=10) -> None`
Основная функция, координирующая весь процесс: получает HTML, парсит его и выводит результаты.

**Параметры:**
- `count` — количество токенов для вывода (по умолчанию 10)

### `main() -> None`
Главная функция программы. Обрабатывает пользовательский ввод и запускает парсинг.

## Важные замечания

### Очистка данных о цене
Цена приводится к формату числа с удалением символа валюты ($), запятых и пробелов:
- `$1,234.56` → `1234.56`

### Обработка ошибок
- Если сайт недоступен или произойдёт ошибка при получении данных, программа выведет сообщение `Error`
- Проверьте подключение к интернету и доступность https://etherscan.io/tokens
